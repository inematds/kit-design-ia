# Kit de diseño con IA

**[Português](README.md) · [English](README.en.md) · [Español](README.es.md)**

## Qué es

Kit de diseño con IA es una selección comentada de tres bibliotecas de instrucciones para asistentes de programación. Está pensado para quienes crean sitios web y quieren orientar mejor el aspecto visual, los efectos y la revisión de calidad. El kit reúne criterios de selección, prompts y un ejercicio para usar Impeccable, MengTo Skills y UI UX Pro Max. Para empezar, basta con leer la guía; para aplicarlo, usa tu asistente de programación y un proyecto local.

## Las tres referencias

- [Impeccable](https://github.com/pbakaus/impeccable): Revisar y perfeccionar una interfaz existente. Licencia upstream: Apache-2.0.
- [MengTo Skills](https://github.com/MengTo/Skills): Elegir una técnica, una referencia visual o un flujo específico. Licencia upstream: MIT.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): Buscar estilos, paletas y directrices para un sistema visual. Licencia upstream: MIT.

## Empieza aquí

1. Abre tu proyecto en el asistente que ya utilizas.
2. Pega el texto de [dirección](prompts/01-direcao.md) y revisa la propuesta.
3. Aplica [implementación](prompts/02-implementacao.md) en una sección.
4. Haz la [revisión](prompts/03-revisao.md) y prueba los controles con el móvil y el teclado.

No es necesario instalar las tres bibliotecas para leer o usar los prompts. Para cargar una skill original, sigue la documentación del repositorio correspondiente y revisa el archivo antes de ejecutarlo. Los prompts no instalan dependencias.

## Ejercicio

Crea una página para un taller gratuito, con fecha real, público, duración e inscripción. Define el sistema visual, implementa el formulario y revísalo en 390 y 1280 píxeles. Está listo cuando la inscripción tenga etiquetas, mensajes de error y confirmación, todos los controles funcionen con el teclado y no haya contenido recortado.
