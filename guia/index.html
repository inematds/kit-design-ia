Em resumo

O Kit Design com IA é uma seleção comentada de três bibliotecas de instruções para assistentes de programação. Serve para quem cria sites e quer orientar melhor o visual, os efeitos e a revisão de qualidade. O kit reúne critérios de escolha, prompts e um exercício para usar Impeccable, MengTo Skills e UI UX Pro Max. Para começar, basta ler o guia; para aplicar, use seu assistente de programação e um projeto local.

O processo

Direção visual→Uma seção funcional→Revisão com evidência

Use hoje no seu projeto

Abra um projeto no assistente de programação que já utiliza. Baixe o kit no GitHub ou abra os arquivos abaixo. Os prompts não instalam ferramentas nem exigem uma API. Para usar uma referência sem instalar, abra o link oficial, escolha a pasta da skill e forneça seu SKILL.md ao assistente como contexto. Se ela não estiver disponível, aplique o checklist do exercício e marque a revisão como manual.

1

Direcao

Leia o contexto do meu projeto. Defina público, ação principal, tom, restrições, hierarquia, tipografia e cores por função. Use UI UX Pro Max como referência quando disponível. Explique cada decisão e preserve a identidade existente. Não invente clientes, métricas ou depoimentos. Entregue uma proposta antes de implementar.

Abrir prompt
2

Implementacao

Leia a direção aprovada. Escolha no MengTo Skills somente a técnica necessária para esta tarefa e leia seu SKILL.md. Implemente uma seção com conteúdo real. Considere celular, teclado e preferência por movimento reduzido. Informe dependências. Serviços externos exigem autorização; não os acione automaticamente.

Abrir prompt
3

Revisao

Use Impeccable para revisar esta interface. Inspecione a página renderizada em celular e desktop. Relate problemas concretos de leitura, contraste, navegação, estados e desempenho, com a localização e a menor correção possível. Corrija os defeitos autorizados, verifique novamente e distinga evidência observada de sugestão estética.

Abrir prompt

Para instalar uma biblioteca original, siga seu README oficial. Escolha a menor skill necessária e revise dependências e serviços antes de executar.

Pratique: uma oficina gratuita

Crie uma página com público, data, duração e formulário de inscrição reais. Defina a direção, implemente uma seção e revise em 390 e 1280 pixels.

Pronto quando

O formulário tem rótulos, erro e confirmação; todos os controles funcionam por teclado; o texto fica legível e nenhum conteúdo é cortado no celular. Confirme o que foi testado de verdade.
