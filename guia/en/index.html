In brief

The AI Design Kit is an annotated selection of three instruction libraries for coding assistants. It is for people who build websites and want to provide clearer direction for the visual design, effects, and quality review. The kit brings together selection criteria, prompts, and an exercise for using Impeccable, MengTo Skills, and UI UX Pro Max. To get started, just read the guide; to put it into practice, use your coding assistant and a local project.

The process

Visual direction→A functional section→Evidence-based review

Use it in your project today

Open a project in the coding assistant you already use. Download the kit from GitHub or open the files below. The prompts do not install tools or require an API. To use a reference without installing it, open the official link, choose the skill folder, and provide its SKILL.md to the assistant as context. If it is unavailable, apply the exercise checklist and mark the review as manual.

1

Direction

Read the context of my project. Define the audience, primary action, tone, constraints, hierarchy, typography, and colors by function. Use UI UX Pro Max as a reference when available. Explain each decision and preserve the existing identity. Do not invent clients, metrics, or testimonials. Deliver a proposal before implementation.

Open prompt
2

Implementation

Read the approved direction. Choose only the technique needed for this task from MengTo Skills, and read its SKILL.md. Implement a section with real content. Consider mobile devices, keyboard access, and reduced-motion preferences. List dependencies. External services require authorization; do not activate them automatically.

Open prompt
3

Review

Use Impeccable to review this interface. Inspect the rendered page on mobile and desktop. Report specific issues with readability, contrast, navigation, states, and performance, including their locations and the smallest possible fix. Correct authorized defects, check again, and distinguish observed evidence from aesthetic suggestions.

Open prompt

To install an original library, follow its official README. Choose the smallest skill you need and review dependencies and services before running it.

Practice: a free workshop

Create a page with real audience, date, duration, and registration form details. Define the direction, implement a section, and review it at 390 and 1280 pixels.

Done when

The form has labels, an error message, and confirmation; all controls work with a keyboard; the text is readable and no content is cut off on mobile. Confirm what was actually tested.
