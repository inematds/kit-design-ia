# AI Design Kit

**[Português](README.md) · [English](README.en.md) · [Español](README.es.md)**

## What it is

AI Design Kit is an annotated selection of three instruction libraries for coding assistants. It is for people who build websites and want to give better direction on visual design, effects, and quality reviews. The kit brings together selection criteria, prompts, and an exercise for using Impeccable, MengTo Skills, and UI UX Pro Max. To get started, just read the guide; to put it into practice, use your coding assistant and a local project.

## The three references

- [Impeccable](https://github.com/pbakaus/impeccable): Review and refine an existing interface. Upstream license: Apache-2.0.
- [MengTo Skills](https://github.com/MengTo/Skills): Choose a specific technique, visual reference, or workflow. Upstream license: MIT.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): Research styles, color palettes, and guidelines for a visual system. Upstream license: MIT.

## Start here

1. Open your project in the assistant you already use.
2. Paste the [direction](prompts/01-direcao.md) text and review the proposal.
3. Apply [implementation](prompts/02-implementacao.md) to one section.
4. Do the [review](prompts/03-revisao.md) and test the controls on mobile and with a keyboard.

You don’t need to install all three libraries to read or use the prompts. To load an original skill, follow the documentation in its respective repository and review the file before running it. The prompts do not install dependencies.

## Exercise

Create a page for a free workshop, with an actual date, intended audience, duration, and registration. Define the visual system, implement the form, and review it at 390 and 1280 pixels. It’s ready when the registration form has labels, error messages, and confirmation; all controls work with a keyboard; and no content is cut off.
