## O que é

O Kit Design com IA é uma seleção comentada de três bibliotecas de instruções para assistentes de programação. Serve para quem cria sites e quer orientar melhor o visual, os efeitos e a revisão de qualidade. O kit reúne critérios de escolha, prompts e um exercício para usar Impeccable, MengTo Skills e UI UX Pro Max. Para começar, basta ler o guia; para aplicar, use seu assistente de programação e um projeto local.

## As três referências

- [Impeccable](https://github.com/pbakaus/impeccable): Revisar e aperfeiçoar uma interface existente. Licença upstream: Apache-2.0.
- [MengTo Skills](https://github.com/MengTo/Skills): Escolher uma técnica, uma referência visual ou um fluxo específico. Licença upstream: MIT.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): Pesquisar estilos, paletas e diretrizes para um sistema visual. Licença upstream: MIT.

## Comece aqui

1. Abra seu projeto no assistente que já utiliza.
2. Cole o texto de [direção](prompts/01-direcao.md) e revise a proposta.
3. Aplique [implementação](prompts/02-implementacao.md) em uma seção.
4. Faça a [revisão](prompts/03-revisao.md) e teste os controles no celular e teclado.

Não é necessário instalar as três bibliotecas para ler ou usar os prompts. Para carregar uma skill original, siga a documentação do respectivo repositório e revise o arquivo antes de executá-lo. Os prompts não instalam dependências.

## Exercício

Crie uma página para uma oficina gratuita, com data real, público, duração e inscrição. Defina o sistema visual, implemente o formulário e revise em 390 e 1280 pixels. Pronto quando a inscrição tiver rótulos, mensagens de erro e confirmação, todos os controles funcionarem por teclado e não houver conteúdo cortado.
